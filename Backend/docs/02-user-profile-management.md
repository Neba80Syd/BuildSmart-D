# Module 02 — User & Profile Management

## Objective
Manage personal, professional, business, and account information for all platform users.

## Functional Requirements
- View/edit profile.
- Upload profile photo.
- Manage contact information and location.
- Maintain role-specific profile fields.
- Display project/history information where applicable.
- Manage account preferences.

## Architect Profile
- Biography
- Specialization
- Experience
- Portfolio
- Credentials
- Verification status
- Ratings

## Vendor Profile
- Business name
- Description
- Location
- Registration information
- Products
- Verification status
- Ratings

## Dependencies
- Authentication
- File Management
- Verification
- Reviews
