# Module 14 — Communication & Chat

## Objective
Provide secure real-time communication among platform participants.

## Communication Types
- Client ↔ Architect
- Client ↔ Vendor
- Architect ↔ Client
- Architect ↔ Vendor
- Admin ↔ Users
- Project-based conversations

## Functional Requirements
- One-to-one messaging.
- Project/group conversations.
- Text messages.
- Images/files.
- Design sharing.
- BOQ sharing.
- Product sharing.
- Read status.
- Online status where supported.

## Technical Direction
Use a real-time transport such as WebSockets or a managed real-time service.
