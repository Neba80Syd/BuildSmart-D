# Module 20 — Administration & Moderation

## Objective
Provide administrators with centralized platform control.

## Admin Dashboard
Monitor:
- Users
- Architects
- Vendors
- Verification requests
- Projects
- AI generations
- Subscriptions
- Payments
- Marketplace
- Orders
- Reviews
- Reports
- Blog content

## Moderation
- Suspend users.
- Verify architects/vendors.
- Remove products/content.
- Moderate reviews.
- Handle complaints.
- Review reports.

## Security
All administrative actions must be authorized and auditable.
