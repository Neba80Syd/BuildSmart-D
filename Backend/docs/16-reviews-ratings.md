# Module 16 — Reviews & Ratings

## Objective
Build trust through ratings and moderated reviews.

## Review Targets
- Architects
- Vendors
- Products
- Services

## Functional Requirements
- Submit rating.
- Write review.
- Edit review where permitted.
- Report review.
- Moderate reviews.
- Calculate average rating.
- Prevent duplicate/unauthorized reviews.

## Example
4.8 / 5 ⭐
