# Module 11 — Construction Marketplace

## Objective
Connect customers with construction material vendors and products.

## Customer Features
- Browse products.
- Search/filter.
- View product details.
- Compare products.
- Add to cart.
- Checkout.
- Track orders.
- Review products.

## Vendor Features
- Manage vendor profile.
- Create/edit products.
- Manage inventory.
- Manage prices.
- Process orders.
- View sales analytics.

## Categories
- Cement
- Blocks
- Steel
- Roofing
- Tiles
- Paint
- Plumbing
- Electrical
- Doors
- Windows
- Finishing materials

## Dependencies
- Vendor Management
- Cart/Orders
- Payments
- Reviews
