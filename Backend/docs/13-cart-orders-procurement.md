# Module 13 — Cart, Orders & Procurement

## Objective
Handle purchasing after users select marketplace products.

## Functional Requirements
- Shopping cart.
- Quantity management.
- Checkout.
- Order creation.
- Payment.
- Order confirmation.
- Order history.
- Cancellation.
- Refund workflow where supported.
- Delivery/order status tracking.

## Order States
CART → CHECKOUT → PAYMENT → CONFIRMED → PROCESSING → SHIPPED → DELIVERED

## Dependencies
- Marketplace
- Payment
- Notifications
- User Profiles
