# Module 23 — Support & Help Center

## Objective
Provide users with assistance and issue resolution.

## Features
- FAQs.
- Help articles.
- Contact support.
- Support tickets.
- User reports.
- Technical assistance.

## Ticket States
OPEN → IN_PROGRESS → WAITING_FOR_USER → RESOLVED → CLOSED

## Admin/Support Features
- Assign tickets.
- Respond.
- Change status.
- Search/filter.
- Maintain ticket history.
