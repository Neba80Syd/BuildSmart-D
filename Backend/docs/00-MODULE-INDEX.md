# BuildSmart AI — Functional Module Index

This directory contains the executable Markdown specifications for the BuildSmart AI platform.

## Implementation Rules

1. Read the technology-stack module before implementation.
2. Inspect the existing codebase before modifying it.
3. Implement modules in dependency order.
4. Reuse existing components, services, database models and infrastructure.
5. Do not duplicate functionality.
6. Protect sensitive information and enforce authorization on the backend.
7. Run tests after each module and again after integration.
