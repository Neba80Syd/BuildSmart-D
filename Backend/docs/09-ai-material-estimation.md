# Module 09 — AI Material Estimation

## Objective
Estimate approximate construction material quantities from project and architectural information.

## Inputs
- Building dimensions
- Floor area
- Number of floors
- Floor plan
- Wall dimensions
- Roof type
- Finishing requirements
- Construction parameters

## Materials
- Cement
- Blocks
- Sand
- Gravel
- Reinforcement bars
- Roofing materials
- Tiles
- Paint
- Plumbing materials
- Electrical materials

## Flow
Architectural Data → Building Parameters → Estimation Engine → Quantities

## Requirements
- Show assumptions.
- Show units.
- Allow manual adjustments.
- Save estimates.
- Provide confidence/estimation notes where possible.

## Important Constraint
All quantities are preliminary estimates and must be professionally validated before procurement or construction.
