# Module 08 — Construction Project Management

## Objective
Manage construction projects from planning through completion.

## Functional Requirements
- Create/edit/archive projects.
- Assign participants.
- Track project status.
- Manage tasks and milestones.
- Store documents.
- Track budgets.
- Track materials.
- Monitor progress.
- Provide project dashboard.

## Project States
- PLANNING
- DESIGNING
- APPROVED
- PROCUREMENT
- CONSTRUCTION
- COMPLETED
- ARCHIVED

## Dependencies
- Authentication
- AI Design
- BOQ
- Marketplace
- Communication
