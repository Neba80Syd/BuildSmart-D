# Module 15 — Architect Discovery & Collaboration

## Objective
Allow clients to discover and contact verified architects.

## Functional Requirements
- Search architects.
- Filter by specialization.
- Filter by location.
- View portfolio.
- View experience.
- View ratings.
- Display verification badge.
- Request consultation/service.
- Start conversation.

## Flow
Find Architect → Filter/Search → Profile → Portfolio → Contact/Request Service
